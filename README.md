# Meu Primeiro Projeto
Olá! Este é o projeto Rota.365, um site simples que eu fiz para aprender HTML, CSS e JavaScript!

A ideia é simular uma página de agência de viagens onde você pode ver destinos, anúncios e, o mais importante, fazer uma reserva.

## O Que Tem Aqui?
<li> Este projeto é feito com 3 arquivos principais:

index.html: É a página principal! Aqui você vê a lista de destinos Nacionais e Internacionais, um menu e um carrossel de fotos.

reserva.html: Esta é a página para fazer a reserva da viagem. É onde você coloca seu nome, data, destino e escolhe o assento.

style.css: Este arquivo deixa o site bonito! Ele tem as cores, as fontes e a organização visual das páginas.

script.js: Este é o cérebro do projeto! Ele faz as coisas funcionarem, como:

Mudar para o Modo Escuro (e ele lembra da sua escolha!).

Fazer o Carrossel de fotos girar.

Calcular o preço da viagem (ele usa a quilometragem do destino e o tipo de assento).

Verificar se a data da viagem não é no passado.

Confirmar a reserva e mostrar um resumo.

## Recursos Legais que Aprendi

Modo Escuro Persistente: Eu usei o localStorage no JavaScript para que, se você ativar o modo escuro, ele continue ativado mesmo quando você recarregar a página! (Isso é bem legal!)

Design Responsivo: O site se adapta para telas pequenas (como celulares) graças aos @media queries no CSS.

Simulação de Cálculo: O preço da viagem é calculado em tempo real usando a distância (km) do destino e um multiplicador para o tipo de assento (Padrão, VIP, Executiva).

## Como Usar

<li> Como é um projeto simples, você não precisa de nada especial.

Baixe ou clone todos os arquivos.

Dê dois cliques no arquivo index.html.

Ele vai abrir no seu navegador!

Navegue pelo menu e clique em "Reservas" para testar a página de reserva!
